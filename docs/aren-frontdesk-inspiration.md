# AREN Front Desk — Inspiration & Direction

Look at these mental references while designing:

**Feels like:**
- Linear (calm, restrained, purposeful color)
- Arc Browser (warmth, personality, delight in small moments)
- Notion (soft, human, quiet confidence)
- Superhuman (density done well, keyboard-fluent, fast)
- Cred / Zomato Pro (Indian, modern, playful without being childish)

**Does not feel like:**
- Bootstrap admin templates
- Hospital software from 2012
- Generic SaaS dashboards
- Government portals
- Corporate healthcare UI

**Signature moves you can borrow:**
- Soft gradients as backgrounds, not just fills
- Warm micro-illustrations for empty states
- Purple + pink used as accents in decorative moments (dividers, glows, 
  brand marks, morning welcome)
- Playful but purposeful icon choices
- Typography with real hierarchy (big is BIG, small is muted)
- Motion that feels physical, not sliding-panel-corporate

**Where to be brave:**
- The Patient Launcher's idle state — make it a beautiful surface
- The empty morning queue — this is where the receptionist meets AREN 
  for the first time each day. Design that meeting.
- The AREN brand mark in the header — make it feel like a real product
- The Doctor Requests card when active — it should feel alive and urgent

**Where to be restrained:**
- Populated queue rows — she's scanning, not admiring. Get out of the way.
- Modals — clear, direct, functional. No decoration inside.
- Status labels — quiet. The row tint carries the signal.

If in doubt: warmer, not cooler. Human, not sterile. Ours, not generic.
